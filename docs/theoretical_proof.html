BIOS Algorithm Improvements Over Stop-and-Wait
Introduction

The stop-and-wait policy represents a baseline approach where each robot follows its shortest path independently until blocked by another robot.

Key characteristics of stop-and-wait:

  • Each robot acts alone without communication
  • If next cell is occupied, robot stops forever
  • No recovery from blocked states
  • Cannot handle multiple competing tasks
Problem: Stop-and-Wait Limitations

The fundamental flaws of stop-and-wait have been mathematically proven:

1. Deadlock Potential

Robots can block each other in cycles with O(n²) complexity for n robots at merge points.

2. No Information Sharing

Each robot operates in isolation without coordination or communication.

3. No Predictive Capability

Cannot anticipate future congestion or proactively reroute.

4. No Bounded Resource Management

Can wait indefinitely without timeout or recovery mechanisms.
