Reading this screen

The dashboard is a passive listener. It reads the same messages the robots broadcast to each other and cannot command anything. The problem statement asks for "no central server" and then for a dashboard aggregating the whole fleet — that is a central aggregator with the same single point of failure, so this one is built to not be one.

Safety is the bottom layer, not the protocol. The onboard protective stop runs at 50 Hz, is sized by its own speed and the closing speed of whatever it sees, and never waits on a packet. The walking worker broadcasts nothing and is the case that proves it.
