Why This Technology Stack?
  • Zero External Dependencies: 100% Python stdlib core runs on bare Raspberry Pi without build steps.
  • Hard Real-Time Safety: Air-gapped 50 Hz onboard LiDAR loop guarantees zero physical collisions.
  • Lightweight Edge AI: 645-parameter neural model (< 3 KB memory) executes in sub-millisecond cycles.
  • Network Fault Resilience: P2P UDP multicast operates seamlessly under 30% packet loss & RF dead zones.
